# KanaCaret

文字を入力している位置(テキストキャレット)のすぐ上に、IME が日本語入力なら「あ」、直接入力なら「a」を表示する Windows 11 用の常駐アプリです。
- 軽量: 何もしていないときの CPU 使用率は 1 コアあたり約 0.1%、メモリは約 6MB
- Windows 11 の見た目に合わせた角丸・影・フェード。ライト/ダークテーマ、アクセントカラー、ハイコントラストに追従
- インストーラー(管理者権限は不要)と、展開するだけで使える zip(exe 1 つ)のどちらでも使える

## 動作環境

- Windows 11(Windows 10 でも動く見込みですが、確認していません)
- Microsoft IME、Google 日本語入力 など

## インストール

[Releases](../../releases) から、次のどちらかをダウンロードします。

- **インストーラー** `KanaCaret-<バージョン>-setup.exe`: 実行すると `%LOCALAPPDATA%\Programs\KanaCaret` に入り、スタートメニューに「KanaCaret」が登録されます。管理者権限は要りません。新しいバージョンに上げるときも、同じように実行するだけです(起動中なら自動で終了し、設定は引き継ぎます)。
- **zip** `KanaCaret-<バージョン>.zip`: 好きなフォルダーに展開し、`KanaCaret.exe` を起動します。

起動すると、通知領域(タスクバーの右端)にアイコンが出ます。

### 「Windows によって PC が保護されました」と表示されたら

インストーラーと exe にはコード署名をしていないため、初めて実行したときに Microsoft Defender SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で実行できます。

心配な場合は、Releases に載せている SHA256 ハッシュと、ダウンロードしたファイルのハッシュが一致するかを確かめてください。

```powershell
Get-FileHash .\KanaCaret-0.3.0-setup.exe -Algorithm SHA256
```

## 使い方

通知領域のアイコンをクリックすると設定画面が開きます(`KanaCaret.exe --settings` でも開けます)。変えた設定はすぐ反映されます。設定画面は Windows のアプリのテーマ(ライト/ダーク)に合わせて表示されます。

| ページ | 項目 |
|---|---|
| 表示 | 表示するとき(入力欄にいる間は常に表示(既定)/ 切り替えたときだけ表示 / 日本語入力のときだけ表示)、入力中は隠す(キー入力の間は隠し、手を止めて 1 秒たつと表示。既定はオフ) |
| 見た目 | 位置(キャレットの上(既定)/ 右上 / 下)、大きさ(14〜40、既定 22)、不透明度(30〜100%)、キャレットとの間隔(0〜16、既定 4)、影の濃さ(0〜200%)、「あ」と「a」の色(見本か任意の色。既定は「あ」がアクセントカラー)。プレビューでライトとダークの見え方を確かめられます |
| アプリ | 表示するアプリ(すべてのアプリ(既定)/ チェックしたアプリだけ)。いまウィンドウを開いているアプリが一覧に並び、チェックを付けたアプリでだけ表示できます |
| 全般 | Windows の起動時に実行(既定はオフ)、バージョン |

アイコンを右クリックすると、「設定...」「一時停止」「終了」を選べます。

フルスクリーンのアプリやゲーム、プレゼンテーション中は自動で隠れます。

## 制限事項

- **スタートメニューの検索欄では表示されません。** スタートメニューは通常のウィンドウより上の層に描かれるため、インジケーターがその下に隠れます(Windows の仕様です)。
- **管理者として実行しているアプリでは表示されません。** Windows のセキュリティの仕組みにより、通常の権限のアプリからは IME の状態を読み取れません。
- 入力位置を外部に公開していないアプリ(独自描画のエディターやゲームなど)では表示されません。

## プライバシー

- インターネットには一切接続しません。
- 入力した文字は読み取りません。手前のアプリに対して、IME の状態(オン/オフ・入力モード)と入力位置の座標だけを問い合わせます。
- 保存するのは設定ファイル `%APPDATA%\KanaCaret\settings.ini` だけです。「Windows の起動時に実行」をオンにすると、レジストリ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に `KanaCaret` を登録します。
- インストーラーを使った場合は、このほかに、インストール先のフォルダー、スタートメニューのショートカット、アンインストール用の情報(`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\KanaCaret`)を書き込みます。

## アンインストール

**インストーラーで入れた場合:** 「設定 > アプリ > インストールされているアプリ」の「KanaCaret」からアンインストールします。起動中のアプリの終了と、「Windows の起動時に実行」の登録の削除も行います。最後に、設定のフォルダー `%APPDATA%\KanaCaret` も削除するかを尋ねます。

**zip で使っている場合:**

1. 「Windows の起動時に実行」をオンにしていた場合は、設定画面でオフにします。
2. メニューの「終了」でアプリを終了します。
3. 展開したフォルダーと、設定のフォルダー `%APPDATA%\KanaCaret` を削除します。

## 開発者向け

Visual Studio 2022 以降(「C++ によるデスクトップ開発」)があれば、`build.cmd` でビルドできます。

- IME の状態は、フォーカスのあるウィンドウの IME ウィンドウに `WM_IME_CONTROL` で問い合わせます。
- 入力位置は、Win32 のシステムキャレット → MSAA → UI Automation の順に試します(アプリによって公開方法が違うため)。
- 描画は Direct2D/DirectWrite で描いた画像を `UpdateLayeredWindow` で表示します。

設計、判断の理由、アプリ別の対応状況、開発手順は [docs/](docs/README.md) にあります。変更履歴は [CHANGELOG.md](CHANGELOG.md)、AI エージェントで開発するときの指示は [AGENTS.md](AGENTS.md) です。
