# KanaCaret

文字を入力している位置(テキストキャレット)のすぐ上に、IME が日本語入力なら「あ」、直接入力なら「a」を表示する Windows 11 用の常駐アプリです。
- 軽量: 何もしていないときの CPU 使用率は 1 コアあたり約 0.1%、メモリは約 6MB
- Windows 11 の見た目に合わせた角丸・影・フェード。ライト/ダークテーマ、アクセントカラー、ハイコントラストに追従
- インストール不要(exe 1 つ)

## 動作環境

- Windows 11(Windows 10 でも動く見込みですが、確認していません)
- Microsoft IME、Google 日本語入力 など

## インストール

1. [Releases](../../releases) から `KanaCaret-<バージョン>.zip` をダウンロードし、好きなフォルダーに展開します。
2. `KanaCaret.exe` を起動します。通知領域(タスクバーの右端)にアイコンが出ます。

### 「Windows によって PC が保護されました」と表示されたら

この exe にはコード署名をしていないため、初めて起動したときに Microsoft Defender SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。

心配な場合は、Releases に載せている SHA256 ハッシュと、ダウンロードした zip のハッシュが一致するかを確かめてください。

```powershell
Get-FileHash .\KanaCaret-0.2.0.zip -Algorithm SHA256
```

## 使い方

通知領域のアイコンをクリック(または右クリック)すると、次の設定を変えられます。

| 項目 | 選択肢 |
|---|---|
| 表示するとき | 入力欄にいる間は常に表示(既定)/ 切り替えたときだけ表示 / 日本語入力のときだけ表示 |
| 位置 | キャレットの上(既定)/ 右上 / 下 |
| 大きさ | 小 / 中(既定)/ 大 |
| 「あ」をアクセントカラーにする | オン(既定)/ オフ |
| 入力位置が分からないときはマウスの位置に表示 | オン(既定)/ オフ |
| 「○○.exe」では表示しない | 直前に使っていたアプリで表示しないようにする |
| Windows の起動時に実行 | オン / オフ(既定) |
| 一時停止 / 終了 | |

通知領域のアイコン自体も、いまの状態(あ / a)を表します。フルスクリーンのアプリやゲーム、プレゼンテーション中は自動で隠れます。

## 制限事項

- **スタートメニューの検索欄では表示されません。** スタートメニューは通常のウィンドウより上の層に描かれるため、インジケーターがその下に隠れます(Windows の仕様です)。
- **管理者として実行しているアプリでは表示されません。** Windows のセキュリティの仕組みにより、通常の権限のアプリからは IME の状態を読み取れません。
- 入力位置を外部に公開していないアプリ(独自描画のエディターやゲームなど)では、IME を切り替えたときだけマウスカーソルの上に表示します。

## プライバシー

- インターネットには一切接続しません。
- 入力した文字は読み取りません。手前のアプリに対して、IME の状態(オン/オフ・入力モード)と入力位置の座標だけを問い合わせます。
- 保存するのは設定ファイル `%APPDATA%\KanaCaret\settings.ini` だけです。「Windows の起動時に実行」をオンにすると、レジストリ `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` に `KanaCaret` を登録します。

## アンインストール

1. 「Windows の起動時に実行」をオンにしていた場合は、メニューでオフにします。
2. メニューの「終了」でアプリを終了します。
3. 展開したフォルダーと、設定のフォルダー `%APPDATA%\KanaCaret` を削除します。

## 開発者向け

Visual Studio 2022 以降(「C++ によるデスクトップ開発」)があれば、`build.cmd` でビルドできます。

- IME の状態は、フォーカスのあるウィンドウの IME ウィンドウに `WM_IME_CONTROL` で問い合わせます。
- 入力位置は、Win32 のシステムキャレット → MSAA → UI Automation の順に試します(アプリによって公開方法が違うため)。
- 描画は Direct2D/DirectWrite で描いた画像を `UpdateLayeredWindow` で表示します。

設計、判断の理由、アプリ別の対応状況、開発手順は [docs/](docs/README.md) にあります。変更履歴は [CHANGELOG.md](CHANGELOG.md)、AI エージェントで開発するときの指示は [AGENTS.md](AGENTS.md) です。
